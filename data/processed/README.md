# Processed Data

This folder contains the datasets created during the data cleaning and feature engineering steps.

## Files

- `clean_taxi_trips.parquet` – cleaned version of the raw NYC Yellow Taxi trip data after removing invalid records and handling data quality issues.
- `feature_engineered_taxi_trips.parquet` – final dataset with additional features created for the analysis, such as trip duration, speed, time-based features, and other derived variables.

These files are generated by the scripts in the `src/` folder and are not included in the GitHub repository because of their size.

To reproduce them, start with the raw NYC TLC data and run the data processing scripts in order.
