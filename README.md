## Dataset

FleetIntel uses the official **NYC Taxi & Limousine Commission (TLC) Yellow Taxi Trip Records**.

**Official source:**
https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page

This project uses:

- yellow_tripdata_2026-03.parquet
- yellow_tripdata_2026-04.parquet
- yellow_tripdata_2026-05.parquet
- taxi_zone_lookup.csv

The raw datasets are not included in this repository.
Please download them from the official TLC website and place them in:

data/raw/
